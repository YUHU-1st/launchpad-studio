适用版本：2.3 · Pulse Canvas。当前软件界面为中文；本手册按实际按钮名称说明操作。

[项目首页](../README.md) · [English guide](GUIDE_EN.md) · [完整截图与视频](SHOWCASE.md) · [VJ 专项指南](VJ.md)

## 安装与首次使用

### 下载哪个文件

| 文件 | 用途 |
| --- | --- |
| `LaunchpadStudio-*-windows-x64.zip` | Windows 桌面程序，完整解压后运行 `LaunchpadStudio.exe`，不需要 Python |
| `LaunchpadStudioRemote-*-android.apk` | Android 8.0+ 手机/平板遥控客户端，电脑仍需运行桌面程序 |
| `SHA256SUMS.txt` | 对照下载文件的 SHA-256 校验值 |
| GitHub 的 Source code 压缩包 | 开发源码，不是免配置的 Windows 程序 |

从 [最新 Release](https://github.com/YUHU-1st/launchpad-studio/releases/latest) 下载。Windows 请解压到具有写入权限的目录，保留完整文件夹结构；不要只复制 EXE，也不要在压缩包内直接启动。Android APK 通过设备的常规安装流程安装；不愿安装 APK 的用户可以直接使用手机浏览器。

基本灯板功能不需要联网。天气、在线歌词查询和首次源码安装依赖下载需要联网；手机遥控只要求电脑与手机在同一个可信局域网。

### 第一次让灯亮起来

1. 用 USB 连接 Launchpad。先退出可能独占 MIDI 端口的 Ableton 等软件。
2. 运行 `LaunchpadStudio.exe`，进入左侧“布局设置”。
3. 点击“扫描并连接全部 Launchpad”，确认设备卡片显示“已连接”。
4. 进入“性能监控”，点击“开始实时监控”。中央预览与设备 LED 应开始更新。
5. 选择左侧整体色彩风格和亮度；返回“布局设置”不会停止当前灯光。

![2.3 扩展性能画布，模拟灯板](media/performance-2.3.jpg)

### 日常使用、停止与退出

左侧切换的是正在浏览的设置页，不是立即切换灯板运行功能。只有点击新模式的“开始”“播放”或“启用”才交接输出。各模式自己的停止按钮停止对应功能；顶部“全部停止并熄灯”同时停止所有功能、音视频、VJ 输出并熄灭灯板。

关闭主窗口会收起到 Windows 系统托盘。右键托盘图标可以重新显示界面或完全退出；它是后台桌面进程，不是安装到 Windows 的服务，也不提供系统开机自启。托盘图标有时位于任务栏的隐藏图标菜单中。

### 升级与备份

先完全退出旧程序，再解压新版本。要保留设置、宏、预设和高分，备份旧程序目录的 `data/settings.json`，在新程序首次启动前复制到新目录相同位置。媒体播放列表保存的是文件路径，原文件需要仍然存在；不要把包含配对 PIN、文件路径或命令的个人设置提交到公开仓库。

## 布局设置与多 Launchpad

“布局设置”负责连接、联动方式、位置和独立功能分配。大多数用户只需自动连接，不必手工配对端口。每块设备都有编号，点击“在实机显示编号”可短暂显示对应 LED 数字后恢复原画面。

![新版布局设置，模拟双板](media/layout-2.3.jpg)

| 联动 | 什么时候用 | 如何开始 |
| --- | --- | --- |
| 扩展画布 | 更宽频谱、像素视频、更大的工具或游戏区域 | 在布局页选扩展，拖动排列；到所需模式页统一开始 |
| 复制画面 | 多块灯板显示同一个灯效 | 选复制；在模式页统一开始 |
| 独立模式 | 一块监控、一块音乐等不同功能 | 选独立，为各设备选择功能，再开始相应功能 |

中央预览保留实际相对布局。在任意模式页拖动设备板块可以移动，拖到另一台设备上会交换位置；比例随横排、竖排或不规则布局变化。扩展模式使用原生像素：横向两块为 16×8，纵向两块为 8×16，间隙也保留；工具/游戏扩大活动区域，而不是拉伸 8×8 的方形画面。

独立模式区分功能路由，但同一功能共享一套引擎和参数，不是每台设备分别运行一套不同配置的播放器。手机端提供同样的布局逻辑。VJ 可以进一步明确选择只驱动其中几块灯板，见下文。

内置型号配置：Launchpad Original/MK1、S、Mini MK1/MK2/MK3、MK2、X、Pro、Pro MK3。RGB 型号输出全彩，旧款红绿灯板映射到硬件可显示的颜色；Pro 适配额外控制行。内置型号配置不等于所有型号都完成了实机回归。

## 性能与温度监控

点击“开始实时监控”后约每 0.5 秒更新一次。CPU、内存、GPU、磁盘空间占用、网络与磁盘吞吐量映射为灯柱；界面显示可读取的 CPU、GPU、主板、存储温度，侧边控制灯提示温度趋势。

“磁盘”是 C 盘空间占用率，不是磁盘忙碌百分比。GPU 占用目前由 NVIDIA `nvidia-smi` 提供，不保证 AMD/Intel GPU 占用可用。CPU/主板等温度依赖传感器、权限和 .NET 8 辅助程序；页面显示“需权限 / 无传感器”不是 0 °C。

确有需要时使用页面的管理员重启按钮，按 Windows 提示自行授权；管理员权限也不能创造不存在的传感器。可先以普通权限使用其他功能。

## 宏按键

1. 进入“宏按键”，点击中央画布中的目标键。
2. 选操作类型，填写内容，选择该按键的独立颜色，然后点“保存按键”。
3. 需要时点“测试执行”；它会真的执行操作，请先确认内容。
4. “启用宏按键灯光”显示已配置按键；“清除当前按键”只清除选中键的功能和颜色。

支持热键、输入文字、文件/程序、网址、命令、PowerShell、媒体控制、按键序列、鼠标操作、系统操作、设置音量与组合动作。示例：

| 操作类型 | 内容示例 |
| --- | --- |
| 热键 | `CTRL+SHIFT+S` |
| 输入文字 | `Launchpad Studio` |
| 打开网址 | `https://github.com/YUHU-1st/launchpad-studio` |
| 媒体控制 | `PLAY`、`NEXT`、`PREV`、`MUTE` |
| 设置音量 | `35`（0–100） |
| 鼠标操作 | `左键`、`右键`、`双击` |

组合动作每行一项，`wait` 的单位是毫秒：

```text
hotkey: CTRL+L
wait: 200
text: https://github.com/YUHU-1st/launchpad-studio
hotkey: ENTER
```

在非游戏模式开启“允许 Launchpad 按键同时触发已配置宏”后，演示不改变，按键仍执行宏；游戏优先接管输入。宏按逻辑键位保存，跨型号复用，并非每块设备一套独立宏库。命令/PowerShell 会以程序当前权限执行，只保存自己理解的内容；按键注入对管理员应用也可能受 Windows 权限限制。

## 视频像素播放器

在电脑端“视频播放”点击“＋ 添加”，选择视频文件，再选择播放列表项并播放。支持 MP4、AVI、MOV、MKV、WebM 等；具体解码取决于文件编码和 OpenCV 的解码能力。

拖动进度条定位，使用上/下一曲、播放/暂停、0.5×–3× 速度，以及“不循环 / 单曲循环 / 列表循环”。列表循环顺序播放全部项目；只有一个项目时自然仍重复同一项。

六种像素滤镜为原色视频、亮度热图、边缘轮廓、单色辉光、镜像万花筒和像素故障。可调整输出帧率（5–30）、饱和度、对比度、伽马和边缘阈值；扩展布局直接生成大画布像素。

当前视频模式只显示画面，不播放视频文件音轨。若需要有声音乐同步场景，使用音乐演示或让外部播放器播放，再选实时拾音/VJ 的系统回放。

[播放器截图与视频](SHOWCASE.md#video)

## 音乐演示

电脑端添加 WAV、MP3、OGG、FLAC 或 AIFF 等音频，分析完成后播放。界面显示估计 BPM、能量、风格与情绪；这些是音频特征启发式标签，不是准确的音乐分类或生成式 AI。

音频与灯光共用播放时间轴，支持拖动定位、暂停、上/下一曲、列表、循环、音量与 0.5×–3× 变速；当前变速会改变音高。手动选择十种风格：频谱、对称频谱、波形、脉冲、涟漪、星云、雨幕、火焰、隧道、棋盘。自动多场景编排属于 VJ 模式，不要把普通音乐模式的分析标签理解为自动切换所有灯效。

[音乐播放器截图与视频](SHOWCASE.md#music)

## 实时拾音与常用音频参数

先让外部播放器播放音乐，再在“实时拾音”选择相应“系统声音 / WASAPI Loopback”设备，或选择麦克风，然后点“开始实时灯光”。切换 Windows 默认输出后要检查采集端点是否仍对应实际发声设备，必要时刷新并重选。

| 参数 | 调节目的 |
| --- | --- |
| 频率下限/上限（Hz） | 限制参与显示的频段，例如观察低频鼓点或更多高频细节 |
| 响度下限/上限（dB） | 控制从暗到满亮的响应范围 |
| 灵敏度 | 调整整体音频响应倍数 |
| 噪声阈值 | 避免安静时底噪持续触发 |
| 动画速度 | 改变灯效运动，不改变音频播放速度 |
| 扩散 | 调整空间扩展观感 |

音乐与拾音共享可视化风格和对应参数。没声音时先检查端点，再看噪声阈值；灯效一直过亮可降低灵敏度、调整响度范围，而不是只降低全局亮度。界面中的约 20–45 ms 是目标延迟，不是对所有声卡和系统的实测保证。

## 记忆设置、预设与复制参数

音乐、实时拾音和视频会自动保存最近调节的细节。点击“保存预设”输入名称，之后从下拉框选择并“加载”；最近五个使用项优先排列，音乐和拾音共享音频预设组，视频有独立预设组。

桌面“默认”恢复该模式细节参数，不会清空媒体或所有宏。“复制参数”→切换模式→“粘贴参数”只应用目标模式存在的对应字段，不会把音频频段强塞进视频设置。

VJ 也自动保存参数，但本版没有 VJ 命名预设、默认或复制按钮。手机支持现有音视频预设的保存/加载，不提供桌面默认与复制/粘贴按钮。

[预设截图与操作说明](SHOWCASE.md#presets)

## 实时 VJ：大屏与灯板分别输出

1. 选择实际音乐回放设备或麦克风。
2. 选固定 GPU 场景或“自动编排”，调整共享配色。
3. 选择画幅、视频宽高与 24/25/30/50/60 FPS；多选投屏显示器，或开启小窗口预览。
4. 若需要 LED，开启“Launchpad 原生 VJ 灯效”，多选目标灯板，再选择原生风格或自动联动。
5. 点击“开始 VJ / 重新开始”；用各自参数分别调整大屏与灯板。

八个 GPU 场景与十二个原生 LED 图案参见 [完整风格图鉴](SHOWCASE.md#vj)。LED 使用黑底亮色、高对比像素或线条，可独立调整速度、强度、密度、对比度和亮度截断。两种输出共享节拍、估计情绪与色彩，但不要求图形一致。

所选灯板尺寸自动按布局计算：单板 8×8、横排双板 16×8、竖排双板 8×16，复制时每板 8×8；不会改变屏幕分辨率。未选灯板继续原模式。原生灯效可仅灯板输出；“原画采样”需打开预览或投屏，因为它下采样 GPU 画面。

多个电脑显示器各显示同一完整画面，不是单个画面横跨多屏。F11/双击切换全屏，Esc 关闭当前输出；关闭最后一个画面窗口会停止 VJ。统一布局中开始另一 LED 模式会接替灯板但保留 VJ 投屏，顶部全部停止才一并关闭。

Alpha 是透明窗口，普通 HDMI/DP 不保留独立透明通道。本版没有 Spout/NDI/DMX、投影网格扭曲或透明视频导出。需要 OpenGL 3.3，实际帧率随 GPU/分辨率/窗口数变化；风格与情绪是估计，BPM 锁定需要数秒。演出前请在实际现场硬件上彩排，并注意快速闪光对光敏人群的影响。

## 工具与游戏

在“工具与游戏”下拉框选择具体项目，再按该项目的开始按钮。

| 项目 | 如何使用 |
| --- | --- |
| 数字时钟 | 开始后显示滚动的 24 小时时间 |
| 日历 | 显示当前日期与星期进度 |
| 天气 | 输入城市开始查询，显示气温、体感、湿度、风速和降水概率；Open-Meteo 服务需联网，无需 API Key |
| 专注计时器 | 设 1–180 分钟；支持暂停/继续、重置 |
| 贪吃蛇 | 选简单/普通/困难，键盘或顶排 `↑ ↓ ← →`；越界从另一侧出现，撞到身体失败，得分提升关卡 |
| 打地鼠 | 按下随机亮起的格子，难度影响反应窗口和机会；每次命中重新给完整反应时间 |
| 瀑布音游 | 导入音乐并先生成谱面，按提示操作落到判定线的音符 |
| 环形音游 | 音符从中心向外圈目标扩散，在到达目标时击打 |

贪吃蛇、打地鼠有实时得分、关卡、高分和得分光效。两种音游支持三档难度、1–5 级音符速度、4–8 键、暂停/继续，显示判定、连击、准确率与最高分；不要将音游暂停支持理解为所有小游戏都能暂停。改变音乐、难度或键数后应重新生成谱面，完成生成再开始。

扩展布局扩大工具/游戏显示与活动区域；手机不开放任何游戏控制。具体键位和当前谱面以界面提示为准，环形音游是原创玩法，不附带商业街机游戏素材。

扩展游戏请把灯板排成连续、无空洞的矩形。游戏按整个布局的矩形边界生成目标，不规则或留空布局可能让目标出现在没有实体按键的位置。

## Android 与手机浏览器遥控

1. Windows 电脑和手机连接同一可信局域网；电脑运行桌面端。
2. 点击电脑顶部“手机遥控”，确认服务启用，查看可访问地址与六位 PIN。
3. 在 Android 客户端填地址和 PIN，或手机浏览器打开该地址后输入 PIN。默认端口为 8765，以电脑显示为准。
4. 首次 Windows 防火墙提示时只为可信专用网络授权；不要配置公网端口映射。

Studio 标签包含全局灯光、性能、音视频、拾音、VJ 与四个工具；“布局”可以拖动设备、切换联动并显示编号；“宏”可以触发、编辑、保存和清除宏。页面顶部持续显示各设备 LED 状态，连接信息在客户端本机记忆并支持重连。

文件需要先在电脑导入，手机操作已有列表和预设，不提供上传音乐/视频。手机不是独立 MIDI 驱动，也不接收电脑音频流。游戏只在桌面/灯板操作；不可把遥控页面理解为手机版游戏机。

### Windows 媒体与音频输出

在电脑打开兼容播放器后，手机“媒体”标签显示当前 Windows 媒体会话的应用、标题、歌手、专辑、封面和进度。可用时提供播放/暂停、上下曲、停止、循环、随机与拖动定位；歌词按元数据从 LRCLIB 查询并同步显示。

能力取决于播放器是否向 Windows GSMTC 暴露接口。没有时间轴/seek 时进度条禁用；不能因为按钮存在就保证任何版本的网易云、PotPlayer 或 AIMP 都支持全部操作。基础媒体键可为播放/上下曲提供后备方式，在线歌词也可能查不到或不匹配。

系统音量、静音和默认输出设备是电脑的真实全局设置，会影响其他程序；切换声卡后要重新确认拾音/VJ 的回放输入。手机负责发控制命令，声音仍在电脑端播放。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 没有发现 Launchpad | USB/供电、其他软件端口占用、设备页面重扫；X 应使用普通 MIDI 端口而非 DAW 配套端口 |
| 宏没有反应 | 是否保存目标键、已启用宏灯光或非游戏宏开关、当前是否游戏、前台应用权限是否更高 |
| 切了页面灯光没有换 | 这是预期行为；在新功能页点击开始才接替，顶部全部停止可立即结束 |
| 关闭主窗口后还有灯光/声音 | 程序仍在托盘运行；右键完全退出或顶部全部停止 |
| 温度不可用 | 传感器/权限/.NET 8；不要把不可用解释为零度 |
| 实时灯光没声音响应 | 选择真正发声的 WASAPI 回放设备或麦克风，检查输入权限及噪声阈值 |
| 手机连不上 | 桌面服务、当前 IP、同 LAN、防火墙专用网络、访客 Wi-Fi 隔离、PIN 是否更换 |
| 手机没有媒体进度 | 播放器没有暴露时间轴或 seek；软件不会编造时长 |
| VJ 帧率不够 | 降低 GPU 输出宽高/窗口数量，使用较低目标 FPS；LED 分辨率独立，无需一起改低 |
| 列表项目无法播放 | 原文件是否移动、编码是否可解码、是否已在电脑导入完整文件 |

崩溃诊断在程序目录 `data/crash.log`、`data/native_crash.log`；VJ 子进程诊断在 `data/vj.log`。报告问题时附版本、Windows/Android 版本、Launchpad 型号、复现步骤及删去敏感路径/PIN 后的日志；不要上传整个个人 `data/settings.json`。
