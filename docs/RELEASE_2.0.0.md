# Launchpad Studio 2 · Matrix / 矩阵

## 中文

2.0.0 是面向多台 Launchpad 的大版本。桌面端和 Android/LAN 遥控器现在都可像 Windows 多显示器一样为设备编号、设置 X/Y 相对位置、选择型号与 MIDI 端口，并在以下三种联动方式间切换：

- **扩展画布**：将频谱、性能灯柱和像素视频原生渲染到更宽或更高的组合画布。
- **复制画面**：所有设备同步显示相同灯光。
- **独立模式**：每台设备分配不同功能，各模式同时运行且按键输入互不干扰。

可通过 LED 数字快速识别实机；新版同时补充 Launchpad X、Mini MK3 和 Pro MK3 的 Windows 缩写端口识别。Android 客户端新增完整 Matrix 编辑器，可从手机预览布局、增删设备、修改编号/位置/模式、显示编号并应用连接。

发布包包含无需 Python 的 Windows x64 压缩包、可直接安装的 Android APK 和 SHA-256 校验文件。

## English

Version 2.0.0 is the major multi-Launchpad release. Both the Windows application and Android/LAN remote can now number devices, arrange X/Y positions, select models and MIDI ports, and switch among three routing modes:

- **Extended Canvas:** native wide/tall spectra, performance bars, and pixel video across the combined surface.
- **Mirror:** identical lighting on every device.
- **Independent Mode:** different functions run concurrently on separate devices without crossing pad input.

LED digits identify physical units, while abbreviated Windows port names for Launchpad X, Mini MK3, and Pro MK3 are now detected. The Android client includes the complete Matrix editor for layout preview, device add/remove, number/position/mode editing, identification, and connection.

The release includes a self-contained Windows x64 ZIP, an installable Android APK, and SHA-256 checksums.
