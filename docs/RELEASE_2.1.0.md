# Launchpad Studio 2.1 · Live Matrix / 实时矩阵

## 中文

2.1.0 将多 Launchpad 设置改造成更直观的实时画布工作流。桌面端与 Android/LAN 遥控器会在每个功能页面显示全部已连接设备的实际 LED 状态，画布比例自动跟随横向、纵向或不规则排布；直接拖动设备即可移动，拖到另一台设备上即可交换位置。

新的一级 **布局设置** 页面使用“一键扫描并连接”自动完成型号识别、MIDI 输入/输出配对和编号，并以三个图形按钮切换扩展、复制和独立联动。扩展与复制模式统一跟随普通功能页面，只有独立模式显示逐台功能分配。手机端具备同样的布局、拖动、实时预览和灯光编号功能，所有下拉框也统一为高对比度深色样式。

发布包包含无需 Python 的 Windows x64 压缩包、可直接安装的 Android APK 和 SHA-256 校验文件。

## English

Version 2.1.0 replaces manual multi-Launchpad setup with a direct live-canvas workflow. The Windows application and Android/LAN remote show the actual LED state of every connected unit on every feature page. The composite scales to horizontal, vertical, and irregular arrangements; drag a device to move it, or drop it on another unit to swap their positions.

The new first-level **Layout Settings** page uses one-tap discovery to detect models, pair MIDI inputs and outputs, and assign device numbers. Three graphical controls select Extended, Mirror, or Independent routing. Extended and Mirror follow the feature started from the normal mode pages; per-device function selectors appear only in Independent mode. Mobile provides the same layout, drag, live-preview, and LED-identification workflow with consistent high-contrast dark controls.

The release contains a self-contained Windows x64 ZIP, an installable Android APK, and SHA-256 checksums.
